# Windows 11 Demo 🪟

A fully functional Windows 11-style desktop environment in your browser!

## Features

✨ **Interactive Desktop UI**
- Authentic Windows 11 design with modern aesthetics
- Taskbar with live clock
- Start Menu with app launcher
- Window management (drag, minimize, maximize, close)

🔐 **Password Protection**
- Login screen with password authentication
- Hint: `password123`

🌐 **Built-in Browser**
- Integrated web browser with address bar
- Navigate to any website (that supports iframes)
- Recommended sites: example.com, about:blank

⚙️ **Settings**
- Dark/Light theme toggle
- Brightness control
- Volume slider
- Sign out button

🎨 **Modern Features**
- Smooth animations and transitions
- Responsive design for mobile devices
- Draggable windows
- Hover effects and interactive elements

## How to Use

1. Open `index.html` in your web browser
2. Enter the password: `password123`
3. Explore the desktop!

### Available Applications

- **🌐 Browser**: Browse the web with the integrated browser
- **⚙️ Settings**: Customize theme and display settings
- **🔐 Lock**: Lock your session

## Browser Limitations

Some websites don't allow embedding in iframes (X-Frame-Options). Try these instead:
- `example.com`
- `about:blank`
- `https://example.org`
- Your own hosted pages

## Installation

Simply clone or download this repository and open `index.html` in your web browser. No server required!

```bash
git clone https://github.com/taskmaster773/windowsdemo11.git
cd windowsdemo11
# Open index.html in your browser
```
